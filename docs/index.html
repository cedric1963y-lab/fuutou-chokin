¥封筒貯金袋分け貯金を、iPhoneで

サポート

対象は iPhone アプリ「封筒貯金 袋分け貯金」（ホーム画面の名前は「封筒貯金」、Bundle ID jp.fuutouchokin.app）です。最終更新: 2026年10月8日。

給料日にお金を「食費」「日用品」「外食」などの封筒に分けて、その中だけでやりくりする封筒貯金（袋分け貯金）を、アプリでできるようにしたものです。現金の封筒を持ち歩かなくても、袋ごとの残りがひと目でわかります。アカウント登録や銀行・カードとの連携はありません。

使い方

  1. はじめに給料日（1〜30日または月末）と、使う封筒を選びます。土日祝のときに前の平日にずらすかも選べます。
  2. 封筒ごとに毎月の予算と色を決めます。封筒は「袋を編集」から追加・並び替えできます。
  3. お金を使ったら、封筒をタップして金額を入れるだけ。メモと日付も残せます。
  4. 給料日になると「袋分け」の案内が出ます。封筒ごとに、残りを繰り越すか貯金へ移すかを選ぶと、新しい期間がはじまります。使いすぎた封筒は、マイナスを繰り越すか 0 にもどすかを選べます。
  5. 「貯金と履歴」で、貯金の合計と、これまでの期間ごとの結果を見返せます。

料金と広告

アプリは無料で、すべての機能を使えます。アプリ内課金やサブスクリプションはありません。かわりに画面の下に広告を表示し、給料日の袋分けや封筒の編集が終わったときに、ときどき全画面の広告が出ることがあります（支出の入力中には出しません）。

データの扱い

封筒・支出・貯金の記録は、この iPhone の中だけに保存します。運営のサーバーへは送りません。アプリを削除すると記録も消えます。広告の配信には Google AdMob を使っています。詳しくは プライバシーポリシー をご覧ください。

よくある質問

Q. 給料日の前に締め直したい
「設定」→「今日で締める」で、今日から新しい期間をはじめられます。

Q. 給料日を変えたい
「設定」→「給料日」で変更できます。記録はそのまま残ります。

Q. 機種変更でデータを移せますか
現在、データの引き継ぎ機能はありません。iPhone のバックアップから復元した場合は残ることがあります。
